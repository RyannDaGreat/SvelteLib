# WORKSTREAM BU — plan

## Audit of the three standing pillars (verified, not rebuilt)

1. **Connections ARE input-side receiver properties.** `state.inputs[port] = {item, port}`,
   stated once in core/nodeflow.js's docblock and read through the single funnel
   `connectionsOf()` (nodeflow.js:397). Fan-in-1 is structural (same object key).
2. **They ARE keyframeable deltas.** Pinned by `tests/nodeflow_test.js:405`
   ("A PATCH MAY DIFFER PER SLIDE: the same items, rewired on slide 2") and
   `:394` (disconnect writes `null`, not a deleted key, so the earlier slide's
   value cannot be inherited back).
3. **Wires ARE derived from the receiver's inputs.** `core/derive.deriveWires`
   (derive.js:1680) walks `n.state.inputs` and emits geometry; BN moved the
   drawing into `render_gpu/ports.js:376`. No wire item, no wire plugin.

## THE MEASUREMENT THAT DECIDES THE DESIGN

`leaves()` descends into the `inputs` map, so a drag-authored connection today
produces leaves at `inputs.in.item` and `inputs.in.port`. Measured:

- `{item:"n1",port:"out"}` → `isEquationValue` **false** on both leaves.
  So a node-ref slot cannot disturb any existing patch.
- `"= osc1"` in `inputs.in` → **already collected** as a slot, kind
  `unresolved` → fails loudly with "has no declared value kind".

So the grammar hole is ONE missing kind, not a new evaluation path. And because
`evaluateState` runs BEFORE `deriveRenderTree` (web/cameraFrame.js:90 →
core/derive.js:508), an equation that resolves to `{item,port}` is a plain
literal by the time `connectionsOf`/`deriveWires` read it — **the wire draws
identically with ZERO changes to BN's derivation.** That is the user's ruling
satisfied by construction.

## Reference grammar: the BARE SLUG, no new constructor

`= osc1` — a lone item slug. Rejected `ref("osc1","out")` because:
- slugs are ALREADY the expression namespace's item vocabulary (resolveRef);
- `makeRef`'s proxy already carries `REF_SEGS`, which is exactly how
  `closest_to_rim(box, …)` takes a widget argument — a lone item ref is an
  established, tested shape in this jail;
- a string-argument constructor would put item names in STRING literals, which
  no rename walk rewrites — `= ref("osc1")` would silently dangle on rename,
  while a slug is derived from the current name at display time by design
  (expressions.js:41 "renames then need NO document rewrites").

Port selection: `= osc1.out` (a segment). Default when omitted = the source's
FIRST declared output.
