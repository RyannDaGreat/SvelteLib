Notes

Rewiring ramps the affected output's guard gain to zero, switches the wire, then ramps back — so live patching never clicks. The call itself returns in microseconds; the wire lands ~33 ms later, which is the real price of not clicking. Press Measure Rewire for this machine's numbers.

The scheduler runs two clocks: a 25 ms JS timer queues events onto the sample-accurate audio clock 100 ms ahead, so main-thread stalls stay inaudible.
